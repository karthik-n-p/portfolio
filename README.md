Welcome to my personal portfolio! I am Karthik NP, a product builder and data engineer.

## 🚀 Overview

This repository contains the source code for my personal website, designed with a focus on clean aesthetics, minimal UI, and a premium user experience. It highlights my journey, skills, projects, and personal interests.

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Vanilla CSS & Custom Design System
- **Hosting**: Vercel

## 💻 Development

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/karthik-n-p/threejs-portfolio.git

# Install dependencies
npm install

# Launch development server
npm run dev
```
